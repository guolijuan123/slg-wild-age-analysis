# 野蛮时代手游新注册用户首周行为分析
> 数据分析项目完整MySQL查询脚本

## 项目简介
对SLG手游《野蛮时代》2018‑03月共计82万+新注册用户首周行为开展分析
- 分析维度：注册流量分布、用户质量、付费分层、消费偏好、PVE/PVP玩法行为
- 使用工具：MySQL（数据提取聚合） + PowerBI（可视化业务洞察）

## 文件说明
- wild_age_analysis.sql：全部MySQL查询源代码
